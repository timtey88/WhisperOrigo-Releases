## Qualification

The owner requested push and public hotfix publication with focused checks.
The committed audio phases previously passed 67 selected tests and inert setup UI
checks; the diagnostic feature passed 35 focused tests, one inert preview/export/
clear UI check and Release compilation. Counts describe overlapping runs, not a
combined independent test count. See the [audio record](audio-reliability-phases-2026-10-27.md)
and [log record](diagnostic-log-2026-10-27.md).

This preparation passed 36 offline release cases and 24 publishing fixtures.
The candidate workflow skipped full app-suite reruns while retaining archive,
Developer ID export, runtime/entitlement, notarization, stapling, Gatekeeper,
extracted ZIP, checksum and Sparkle signature validation. Documentation validation
checked 176 local links/anchors and whitespace.

The exact notarized ZIP launched temporarily on the owner's macOS 26.7.1 Mac.
A meter-only check received 153600 raw frames at 48 kHz, with 32 non-silent buffers
and no unmetered buffers, then stopped cleanly. Completed technical events survived
a real quit/reopen. No audio was saved, no model was downloaded, no permission was
granted/reset, and the installed app bundle was not replaced.
