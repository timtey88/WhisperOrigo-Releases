# WhisperOrigo 1.0.0

The first stable release of private, local dictation for macOS.

**Contents:** [Features](#features) · [Requirements and installation](#requirements-and-installation) · [Privacy and updates](#privacy-and-updates) · [Limitations](#limitations)

## Features

- Dictate with a configurable shortcut, using toggle or hold recording.
- Keep transcripts in the app, copy them, or paste into your active app.
- Apply optional on-device cleanup, vocabulary replacements, and filler removal.
- Choose your audio input and channel, preview microphone levels, and customize recording cues and the transcript overlay.
- Opt into local history with playback, favorites, retries, transcript versions, and retention controls.
- Customize appearance and login startup, view diagnostics, and check for updates from Settings.

## Requirements and installation

Requires an Apple silicon Mac running macOS 26.0 or later. Download the release ZIP, unzip it, and move WhisperOrigo.app into /Applications before launching it.

Allow microphone access for recording. Accessibility access enables the global shortcut and automatic paste. Start with the default Right Option shortcut, or record from the app while setting up permissions.

## Privacy and updates

Transcription and optional cleanup run on this Mac. There are no accounts, cloud transcription, analytics, or telemetry. History is off by default; enabling it retains recordings and transcripts locally.

Speech assets may need an initial download. App updates use Sparkle and signed downloads. Automatic update checks are off by default; use **Settings → About → Check for updates…** to check manually.

## Limitations

Speech availability depends on the selected language and installed assets. Optional cleanup also depends on Apple Intelligence readiness and language support; when unavailable, the app keeps the raw transcript. Offline dictation requires the relevant speech assets to be installed first.

Intel Macs are not supported by this release. macOS permissions and external apps can affect shortcut delivery and automatic paste.
