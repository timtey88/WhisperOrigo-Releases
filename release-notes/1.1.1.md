# WhisperOrigo 1.1.1

Improve global shortcut permission diagnosis and recovery after app updates.

**Contents:** [Shortcut recovery](#shortcut-recovery) · [Development isolation](#development-isolation)

## <a id="shortcut-recovery"></a>Shortcut recovery

- A **Shortcut needs attention…** menu item opens Dictation settings when the
  keyboard listener is unavailable.
- Input Monitoring is checked separately from Accessibility. Troubleshooting
  and diagnostic summaries identify effective keyboard-listening access.
- **Retry** replaces a disabled listener. **Recovery steps** explains how to
  repair a stale macOS permission entry without deleting app data.
- Permission requests remain explicit user actions. Automatic paste continues
  to require Accessibility; keyboard listening follows Input Monitoring access.

## <a id="development-isolation"></a>Development isolation

Local Debug builds use a separate app identity, preferences and storage so they
cannot overwrite the released app’s permissions or data. Production updates
remain available only in Release builds.
