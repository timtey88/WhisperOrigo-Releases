# WhisperOrigo 1.1.2

Improve first-use setup and recovery when speech preparation stalls.

**Updated build 4:** if you installed an earlier 1.1.2 (4), download this release and replace the app manually. The version number is unchanged, so the updater cannot distinguish the earlier build.

**Contents:** [Setup](#setup) · [Speech recovery](#speech-recovery) · [Compatibility](#compatibility)

## <a id="setup"></a>Setup

- Set up a working keyboard shortcut or choose **Use menu** without requiring keyboard access.
- Review the selected speech model, Apple language, and asset readiness without preloading models.
- Try real dictation with history, cleanup, and automatic text delivery disabled for the test.
- Reopen focused permission repair when required access is missing on launch.

## <a id="speech-recovery"></a>Speech recovery

- Show speech preparation stages in the menu, Settings status, and diagnostic summary.
- Surface Apple Speech analysis failures and provide guidance when preparation or cleanup takes too long.
- Prevent cancelled Apple Speech analysis from starting a competing finalization while cancellation is finishing.
- Let Cancel reach Apple Speech while a previous Stop is still finishing.
- Keep recording when a delayed audio configuration notification arrives with the engine running and its capture format unchanged.
- Prevent cancelled startup from opening microphone capture later; bound the wait for quitting during stalled preparation.
- Cancel stalled recognition after Stop with recovery guidance and protection against partial text delivery.
- Keep repeated startup-stage reports from extending preparation deadlines.
- Explain first-start preparation, asset installation, and pending cleanup in Settings and setup.
- Retain on-demand loading and the existing Parakeet idle cache.

## <a id="compatibility"></a>Compatibility

Requires Apple silicon and macOS 26.0 or later.
